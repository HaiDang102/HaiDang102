## Giới thiệu
Mình là sinh viên năm 4 ngành **Information Systems** tại **Đại học Công nghiệp TP.HCM (IUH)**, định hướng trở thành **Business Analyst / System Analyst**.  
Mình quan tâm đến việc kết nối giữa **nghiệp vụ** và **công nghệ** để tạo ra những giải pháp rõ ràng, thực tế và hiệu quả.

## Mục tiêu
- Nâng cao kỹ năng phân tích nghiệp vụ  
- Phát triển tư duy mô hình hóa hệ thống  
- Củng cố nền tảng cơ sở dữ liệu và SQL  
- Xây dựng portfolio dự án thực tế
